# 日语语法索引（N5→N4 核心）附动漫例句

## 五十音（あいうえお）

**注意**：以下为日语学习的绝对起点。不熟五十音之前不要学任何语法。

- 平假名（ひらがな）：日常使用，语法词尾、助词全部用假名
- 片假名（カタカナ）：外来语、拟声词、强调
- 濁音（がぎぐげご）、半濁音（ぱぴぷぺぽ）、拗音（きゃきゅきょ）

**玩家常遇**：魔法名（ファイア、サンダー）、角色名（サスケ、ルフィ）全是片假名

## N5 核心语法

### 1. 肯定/否定判断句

```
AはBです。     → A是B
AはBじゃありません。 → A不是B
AはBですか？   → A是B吗？
```

**动漫例**：「私はルフィです！海賊王になる男だ！」（我是路飞！要成为海贼王的男人！）

### 2. こそあど（指示词）

```
これ（近） それ（中） あれ（远） どれ（疑问）
このN そのN あのN どのN
ここ（场所） そこ あそこ どこ
```

**动漫例**：「これは俺の弁当だ！」（这是我的便当！）

### 3. 助词基础

| 助词 | 用法 | 例句 |
|------|------|------|
| は | 主题标记 | 私は学生です。 |
| が | 主语标记/新信息 | 桜が咲きました。 |
| を | 宾格 | ご飯を食べます。 |
| に | 时间/方向/对象 | 8時に学校に行きます。 |
| で | 动作场所/手段 | 電車で帰ります。 |
| へ | 方向 | 家へ帰ります。 |
| と | 共同动作/引用 | 友達と話します。 |

**关键区分**：は vs が
- は：已知信息/主题/对比（「私は知ってる」→关于我，我知道）
- が：新信息/焦点/现象（「雨が降ってる」→客观描述下雨）

**动漫例**：「俺がガンダムだ！」（我就是高达！—が表强调主语）

### 4. 动词て形（最重要的变形之一）

**变形规则**：
- 五段（グループ1）：
  - う→って：買う→買って
  - く→いて：書く→書いて（※ぐ→いで：泳ぐ→泳いで）
  - す→して：話す→話して
  - つ→って：待つ→待って
  - ぬ→んで：死ぬ→死んで
  - ぶ→んで：遊ぶ→遊んで
  - む→んで：読む→読んで
  - る→って：作る→作って
- 一段（グループ2）：る→て：食べる→食べて
- 不規則（グループ3）：する→して、来る→来て（きて）

**动漫例**：「待って！それやばいって！」（等等！那个不妙啊！）

### 5. た形（过去形）

て形把て→た、で→だ即可：食べて→食べた、読んで→読んだ

**动漫例**：「昨日、映画を見た。」（昨天看了电影。）

### 6. ない形（否定形）

**变形规则**：
- 五段：う段→あ段+ない：買う→買わない、書く→書かない（※ある→ない）
- 一段：る→ない：食べる→食べない
- 不規則：する→しない、来る→来ない（こない）

**动漫例**：「そんなの、絶対に許さない！」（那种事，绝对不原谅！）

### 7. い形容詞・な形容詞

```
い形容詞：直接修饰名詞（高いビル）→ 否定：くない（高くない）
な形容詞：+な修饰名詞（静かな部屋）→ 否定：じゃない（静かじゃない）
```

**动漫例**：「この世界は広いなあ。」（这个世界真广阔啊。）

## N4 核心语法

### 8. 〜ている（进行/状态/习惯）

**含义**：
- 動作進行中：「食べている」（正在吃）
- 結果状態：「結婚している」（已婚）
- 習慣：「毎日走っている」（每天在跑）

**口语缩略**：〜ている → 〜てる

**动漫例**：「何を言ってるの？」（你在说什么呢？—口语缩略）

### 9. 〜てある（结果状态，人为）

**含义**：某人做了某事后的状态残留。用が标记对象。
「ドアが開けてある」（门开着—人为打开的）

**vs 〜ている**：〜てある强调人为结果，〜ている只描述状态

### 10. 〜ておく（预先做）

**含义**：为将来做准备而做某事
「予約しておいて！」（先预约好！）

**口语缩略**：〜ておく → 〜とく

**动漫例**：「先に言っとくよ、俺は強いぞ。」（先跟你说好，我很强哦。—言っとく=言っておく）

### 11. 〜てしまう（完了/遗憾）

**含义**：
- 完了：「食べてしまった」（吃完了）
- 遗憾：「忘れてしまった」（不小心忘了）

**口语缩略**：〜てしまう → 〜ちゃう（て→ち）、〜でしまう → 〜じゃう（で→じ）

**动漫例**：「やっちゃった…」（搞砸了…—やってしまった）

### 12. 〜てもいい / 〜てはいけない / 〜なければならない

```
〜てもいい：可以做...
〜てはいけない：不可以做...（口语常缩略为〜ちゃダメ）
〜なければならない：必须做...（口语常缩略为〜なきゃ/〜なくちゃ）
```

**动漫例**：「ここで戦っちゃダメだ！」（不可以在这里战斗！—戦っちゃダメ=戦ってはいけない）

### 13. 〜たことがある（经历）

**含义**：有过...的经历
「日本に行ったことがある」（去过日本）

**口语**：〜たことある

### 14. 〜たい / 〜たがる（愿望）

- 〜たい（第一人称/疑问）：「食べたい」（想吃）
- 〜たがる（第三人称）：「彼は食べたがっている」（他想吃）
- 〜たい的口语：〜てえ（男/青年语）

**动漫例**：「ラーメン食いてえ！」（好想吃拉面！—食いてえ=食べたい的男語）

### 15. 授受表現（あげる/くれる/もらう）

**核心逻辑**：方向性最重要

| 动词 | 方向 | 恩惠 |
|------|------|------|
| あげる（やる） | 我→别人（或别人→别人） | 我给 |
| くれる（くださる） | 别人→我（或别人→我方） | 别人给我 |
| もらう（いただく） | 从别人那得到 | 我收到 |

**〜てあげる / 〜てくれる / 〜てもらう**：做某事于某人/为某人做某事

**动漫例**：「僕が守ってあげる！」（我会保护你的！—给恩惠的语气）
「友達が助けてくれた。」（朋友救了我。—从别人→我）
「先生に教えてもらった。」（跟老师学了。—我收到恩惠）

### 16. 条件形（たら/ば/と/なら）

| 形 | 用法 | 特点 |
|----|------|------|
| 〜たら | 如果...的话 | 最通用，前件后件独立 |
| 〜ば | 如果...就... | 前件是后件的条件（恒常/习惯） |
| 〜と | 一...就... | 必然结果，后件不能是意志/命令 |
| 〜なら | 如果是...的话 | 针对对方的话题 |

**动漫例**：
「明日雨だったら、試合は中止だ。」（要是明天下雨，比赛就取消。—たら）
「春になれば、桜が咲く。」（一到春天，樱花就开。—ば）
「ここを押すと、ドアが開く。」（按这里，门就开。—と）
「行くなら、早くしろよ。」（要去的话，就快点。—なら）

### 17. 可能形（〜られる / 〜ける / できる）

**变形规则**：
- 五段：う段→え段+る：書く→書ける、話す→話せる
- 一段：る→られる：食べる→食べられる
- 不規則：する→できる、来る→来られる（こられる）

**口语**：一段可能形常省略ら（ら抜き言葉）：食べられる→食べれる

**动漫例**：「そんなの、できるわけないだろ！」（那种事，怎么可能做得到！）

### 18. 意向形（〜よう / 〜う）

**含义**：表示意志/建议（"一起做吧"）

**变形规则**：
- 五段：う段→お段+う：行く→行こう、話す→話そう
- 一段：る→よう：食べる→食べよう
- 不規則：する→しよう、来る→来よう（こよう）

**动漫例**：「さあ、行こう！」（好了，走吧！）

### 19. 〜から / 〜ので（原因理由）

- 〜から：主观原因，后接意志/命令/请求（主観的）
- 〜ので：客观原因，后接事实/状态（客観的，更礼貌）

**口语**：〜から → 〜し、〜ので → 〜んで

**动漫例**：「危ないから、下がって！」（因为危险，退后！—から主观警告）
「怖かったので、声が出なかった。」（因为太害怕，说不出话。—ので客观陈述）

### 20. 〜と思う / 〜と言う

- 〜と思う：我认为...（想的内容）
- 〜と言う：某人说...（说的内容）

**动漫例**：「僕は、人間は誰でも強くなれると思う。」（我认为，人类谁都能变强。）

### 21. 受身形（〜られる / 〜れる）

**变形规则**：
- 五段：う段→あ段+れる：書く→書かれる、話す→話される
- 一段：る→られる：食べる→食べられる
- 不規則：する→される、来る→来られる（こられる）

**三种用法**：
1. 直接被动：「先生に叱られた」（被老师骂了）
2. 持ち主受身：「財布を盗まれた」（钱包被偷了）
3. 間接受身（受害）：「雨に降られた」（被雨淋了—受害语气）

**动漫例**：「こんなやつに負けるわけにはいかない！」（怎么能输给这种家伙！—負ける表被动）

### 22. 使役形（〜せる / 〜させる）

**变形规则**：
- 五段：う段→あ段+せる：行く→行かせる、書く→書かせる
- 一段：る→させる：食べる→食べさせる
- 不規則：する→させる、来る→来させる（こさせる）

**含义**：让/使某人做某事

**动漫例**：「俺に行かせてくれ！」（让我去吧！）

### 23. 敬语入门

**尊敬語（抬高对方）**：
- お〜になる：お書きになる / お話しになる
- 特殊形：いらっしゃる（いる/来る）、おっしゃる（言う）、召し上がる（食べる）

**謙譲語（降低自己）**：
- お〜する：お書きする / お話しする
- 特殊形：参る（行く/来る）、申す（言う）、いただく（食べる/もらう）

**动漫常见**：角色语里的敬语区分
- 丁寧角色（敬体）：「そうですね…わかりません」
- タメ口角色（简体）：「そうだな…わかんねえ」
- 女王様/お嬢様：「〜ですわ」「〜ますの」

### 24. 〜てくる / 〜ていく（方向性）

- 〜てくる：动作从远→近（回来/过来/开始）
  - 「帰ってくる」（回来）「雨が降ってきた」（开始下雨了）
- 〜ていく：动作从近→远（去/下去/继续）
  - 「持っていく」（拿过去）「生きていく」（活下去）

**动漫例**：「追ってくるな！」（别跟过来！）
「このまま生きていけるのか…」（能这样活下去吗…）
