# 日语学习路线图 — 从0到生肉自由

## 总览

| 阶段 | 水平 | 词汇量 | 生肉能力 | 累计时间(每日1h) |
|------|------|--------|----------|-----------------|
| 0 | 纯零基础 | 0 | ❌ | 0 |
| 1 | 五十音 | ~50 | ❌ | 2周 |
| 2 | 初级前半 (N5) | ~500 | ❌ | 2-3个月 |
| 3 | 初级后半 (N4前) | ~1000 | 简单日常番（有画面辅助理解） | 4-5个月 |
| 4 | 中级前期 (N4) | ~2000 | 日常番听懂70% | 6-8个月 |

## 阶段0 → 阶段1：五十音（2周）

**目标**：平假名+片假名看到能直接读，不需要想

**核心任务**：
- 平假名46字（清音）→ 浊音/半浊音/拗音
- 片假名46字（同上）
- 简单单词的假名认读（わたし、すし、くるま）

**里程碑**：
- [ ] 平假名任意一个字抽出来，1秒内能读
- [ ] 片假名同上
- [ ] 看到「ヴァイオリン」能读出来（バ・イ・オ・リ・ン）
- [ ] 能写自己的名字（片假名）

**技巧**：
- 联想记忆法（あ=安、か=加、さ=左...）
- Tofugu 的 Learn Hiragana / Katakana 网站（有 mnemonic）
- 用 Anki 刷五十音卡片（每天10分钟，两周就够）

## 阶段1 → 阶段2：初级前半 / N5（2-3个月）

**目标**：掌握基础语法框架，能造简单句子

**语法核心**：
- 名词句：AはBです。AはBじゃありません。
- 疑問文：～か？
- こそあど：これ/それ/あれ/どれ
- 動詞分類：グループ1（五段）/グループ2（一段）/グループ3（不規則）
- 動詞のます形：話します/食べます/来ます/します
- 形容詞：い形容詞 vs な形容詞
- 助詞：は/が/を/に/で/へ/と/から/まで
- て形：作る→作って、食べる→食べて、する→して
- た形（過去形）
- ない形（否定形）
- 存在文：ある/いる

**词汇**：日常词汇200-500个（数字、颜色、食物、家族、天気、仕事）

**推荐练习**：
- 教材：标准日本语 初级上（第1-12课）
- 每天写3句日記（超简单：今日は学校に行きました。）
- 用Anki刷N5词汇

**里程碑**：
- [ ] 能说出动词て形/た形/ない形的变形规则
- [ ] 能区分「は」和「が」的基本用法
- [ ] 能造"私は昨日、友達と映画を見ました"这种句子
- [ ] 看到「食べない」「飲まない」「来ない」能理解否定

## 阶段2 → 阶段3：初级后半 / N4前半（2-3个月）

**目标**：能表达复杂一点的句子，开始接触mini生肉

**语法核心**：
- て形延伸：〜ている（进行/状态）、〜てある（结果状态）、〜ておく（预先）、〜てしまう（完了/遗憾）
- 〜てもいい / 〜てはいけない / 〜なければならない
- 〜たことがある（经历）
- 〜たい / 〜たがる（愿望）
- 〜くれる / 〜あげる / 〜もらう（授受关系）
- 〜から / 〜ので（原因理由）
- 〜と思う / 〜と言う
- 条件形：〜たら / 〜ば / 〜と / 〜なら
- 可能形：食べられる / 行ける / できる
- 意向形：食べよう / 行こう / しよう

**词汇**：加500个，共~1000（含常用动词て形、可能形变形）

**推荐练习**：
- 教材：标准日本语 初级上（第13-24课）+ 初级下
- 开始看儿童番/简单日常番（しろくまカフェ、ちびまる子ちゃん）
- 开日语字幕，遇到不懂的停下來查

**里程碑**：
- [ ] 能说出5种〜て形延伸的用法区别
- [ ] 能看到「食べられる」「飲める」「来られる」知道是可能形
- [ ] 能区分「〜てあげる」「〜てくれる」「〜てもらう」
- [ ] 开字幕能看懂50%的日常番台词

## 阶段3 → 阶段4：中级前期 / N4（2-3个月）

**目标**：能听懂日常番60-70%，开始接触简单漫画

**语法核心**：
- 〜すぎる（过度）
- 〜やすい / 〜にくい（容易/难）
- 〜ながら（一边...一边）
- 〜ばかり（光做...）
- 〜てくる / 〜ていく（方向性）
- 〜ため（为了）
- 〜ことにする / 〜ことになる（決定/結果）
- 〜ようになる（变得...）
- 受身形：食べられる / 書かれる / 来られる
- 使役形：食べさせる / 書かせる
- 敬语：尊敬語（お〜になる） vs 謙譲語（お〜する）
- 〜そうだ（传闻） vs 〜そうだ（样态）

**词汇**：加500个，共~1500-2000

**口语缩略**（开始接触）：
- 〜ている → 〜てる
- 〜ておく → 〜とく
- 〜てしまう → 〜ちゃう / 〜じゃう
- 〜なければ → 〜なきゃ / 〜なくちゃ
- 〜のだ → 〜んだ / 〜ん
- 〜という → 〜って

**推荐练习**：
- 漫画：よつばと!、ドラえもん、クレヨンしんちゃん
- 番剧：日常系（けいおん!、ゆるキャン△、氷菓）
- 听力：開日语字幕→聽一遍→看字幕确认→再聽一遍
- 阅读：用Yomichan（浏览器插件）读简单新闻

**里程碑**：
- [ ] 看到「〜ちゃう」「〜とく」「〜なきゃ」能还原原形
- [ ] 能区分「〜そうだ（传闻）」和「〜そうだ（样态）」
- [ ] 能读懂よつばと!的一话（不查字典能理解60%）
- [ ] 日常番关字幕能听懂50%以上

## 阶段4 → 阶段5：中级 / N3（3-4个月）

**目标**：日常番无压力，简单漫画可读，能参与简单日语对话

**语法核心**：
- 〜てくれる / 〜てもらう 延伸（被动受益）
- 〜せられる（使役被动）
- 〜わけ（原因/道理）：〜わけがない / 〜わけではない
- 〜はず（应该/按理）：〜はずだ / 〜はずがない
- 〜もの（物/事/感叹）：〜ものだ / 〜ものではない
- 〜ようだ / 〜みたいだ / 〜らしい（比况）
- 〜に対して / 〜について / 〜によって（关于/根据）
- 〜ばかりでなく / 〜だけでなく（不仅...而且）
- 〜たとたん（刚一...就）
- 〜ついでに（顺便）
- 〜かと思うと（刚觉得...就）

**词汇**：加1000个，共~3000。重点：抽象名词、复合动词、惯用句

**动漫口语**：
- 〜ってば：强调/不耐烦（だから言ったってば！）
- 〜っけ：确认记忆（そうだったっけ？）
- 〜じゃん：〜じゃないか的口语（いいじゃん！）
- 〜って：引用/传闻（〜って言ってたよ）
- 〜なよ：轻微命令（やめなよ）
- 〜てよ：请求（見せてよ）
- 〜かよ：反问/惊讶（マジかよ！）

**推荐练习**：
- 漫画：SPY×FAMILY、古見さんは、コミュ症です。
- 番剧：一般向（進撃の巨人、呪術廻戦—有设定但口语自然）
- 听力：用Podcast（日本語の森、Let's Learn Japanese from Small Talk）
- 阅读：Yahoo!ニュース（簡単版）、NHK News Web Easy
- 输出：HelloTalk 或 LangCorrect 写短文

**里程碑**：
- [ ] 日常番关字幕能听懂70%+
- [ ] 能读一话SPY×FAMILY（不查字典理解80%）
- [ ] 能区分「〜はず」「〜わけ」「〜もの」的语气差异
- [ ] 看到「〜ってば」「〜っけ」「〜じゃん」能理解

## 阶段5 → 阶段6：中高级 / N2（6-8个月）

**目标**：主流漫画+番剧基本无障碍

**语法核心**：
- 〜ざるを得ない（不得不）
- 〜かねる（难以）/ 〜かねない（有可能）
- 〜に違いない（一定）
- 〜に過ぎない（只不过）
- 〜を問わず（不论）
- 〜も〜ば〜も（既...又...）
- 〜ばかりか / 〜どころか（不仅...反而...）
- 〜ことから（因为...）
- 〜に伴って / 〜とともに（随着）
- 〜をきっかけに（以...为契机）
- 〜て以来（自从...以来）
- 〜つつも（虽然...但是）
- 仮定/逆接：〜としても / 〜にしても / 〜にもかかわらず

**语体切换**：自然掌握简体/敬体切换，能理解角色语（キャラ語尾）

**词汇**：加2000个，共~5000。含：新闻语、抽象语、拟声拟态语

**拟声拟态词**：
- ワクワク（兴奋）、ドキドキ（心跳）、イライラ（烦躁）
- ピカピカ（亮闪闪）、グチャグチャ（乱七八糟）
- 漫画特有：ドーン（爆炸）、バキッ（折断）、ズルッ（滑倒）

**角色语**：
- 〜でござる（武士/忍者）、〜じゃ（老人/キャラ）
- 〜だぜ / 〜だぞ（男らしい）
- 〜わよ / 〜わね（女性语）
- 〜っす（体育会系/口语）

**推荐练习**：
- 漫画：一般向（僕のヒーローアカデミア、鬼滅の刃、ハイキュー!!）
- 番剧：任何题材，开始尝试关字幕
- 阅读：ライトノベル（ラノベ）、ネット小説
- 听力：YouTube 生配信、ゲーム実況
- 游戏：ゼルダの伝説、ポケモン（RPG类，大量文本）

**里程碑**：
- [ ] 主流漫画一话（鬼滅/ハイキュー級）不查字典读到80%理解
- [ ] 番剧关字幕能听懂80%+，生词不影响整体理解
- [ ] 能区分角色语（〜だぜ vs 〜わよ）
- [ ] 能写500字左右日文短文（语法基本正确）

## 阶段6 → 阶段7：高级 / N1（1年+）

**目标**：全类型生肉自由

**语法核心**：
- 文語文法（古语残留）：〜ぬ（否定）、〜ず（否定连用）
- 〜まい（否定推量）
- 〜んがため（为了...）
- 〜こととて（由于...）
- 〜があまり（因为过于...）
- 〜や否や（刚...就...）
- 〜をものともせずに（不顾...）
- 敬語完整体系：尊敬語+謙譲語+丁寧語+美化語

**词汇**：加3000+, 共8000+。含：四字熟語、故事成語、専門用語

**推荐练习**：
- 小说：夏目漱石、太宰治、村上春樹（现代日语）
- 新闻：朝日新聞社説、日経新聞
- 番剧：任何类型，包括时代剧、SF、推理
- 漫画：ジョジョの奇妙な冒険（独特用语）、ワンピース（方言+造语）

**里程碑**：
- [ ] 生肉番剧（含方言/古语）无字幕看懂95%+
- [ ] 漫画（含找造语、特殊设定）无压力阅读
- [ ] 能看懂新闻社説
- [ ] 能读简单的现代日本小说

## 加速技巧（总）

1. **每天30分钟 > 周末5小时** — 语言学习靠频率不靠时长
2. **主动输出 > 被动输入** — 写日記、说句子比看番有效
3. **Anki 是神** — 每天10分钟复习，记忆曲线最大的敌人是遗忘
4. **中国人优势** — 利用汉字优势，但小心和制汉语陷阱
5. **阶段匹配** — 永远不要学超出当前阶段2级以上的内容，会劝退
6. **兴趣驱动** — 想学什么学什么，你喜欢的内容就是最好的教材
