# 日语语法索引（N5→N4 核心）附动漫例句

## 五十音（あいうえお）

**注意**：以下为日语学习的绝对起点。不熟五十音之前不要学任何语法。

- 平假名（ひらがな）：日常使用，语法词尾、助词全部用假名
- 片假名（カタカナ）：外来语、拟声词、强调
- 濁音（がぎぐげご）、半濁音（ぱぴぷぺぽ）、拗音（きゃきゅきょ）

**玩家常遇**：魔法名（ファイア、サンダー）、角色名（サスケ、ルフィ）全是片假名

## N5 核心语法

### 1. 肯定/否定判断句

```
AはBです。     → A是B
AはBじゃありません。 → A不是B
AはBですか？   → A是B吗？
```

**动漫例**：「私はルフィです！海賊王になる男だ！」（我是路飞！要成为海贼王的男人！）

### 2. こそあど（指示词）

```
これ（近） それ（中） あれ（远） どれ（疑问）
このN そのN あのN どのN
ここ（场所） そこ あそこ どこ
```

**动漫例**：「これは俺の弁当だ！」（这是我的便当！）

### 3. 助词基础

| 助词 | 用法 | 例句 |
|------|------|------|
| は | 主题标记 | 私は学生です。 |
| が | 主语标记/新信息 | 桜が咲きました。 |
| を | 宾格 | ご飯を食べます。 |
| に | 时间/方向/对象 | 8時に学校に行きます。 |
| で | 动作场所/手段 | 電車で帰ります。 |
| へ | 方向 | 家へ帰ります。 |
| と | 共同动作/引用 | 友達と話します。 |

**关键区分**：は vs が
- は：已知信息/主题/对比（「私は知ってる」→关于我，我知道）
- が：新信息/焦点/现象（「雨が降ってる」→客观描述下雨）

**动漫例**：「俺がガンダムだ！」（我就是高达！—が表强调主语）

### 4. 动词て形（最重要的变形之一）

**变形规则**：
- 五段（グループ1）：
  - う→って：買う→買って
  - く→いて：書く→書いて（※ぐ→いで：泳ぐ→泳いで）
  - す→して：話す→話して
  - つ→って：待つ→待って
  - ぬ→んで：死ぬ→死んで
  - ぶ→んで：遊ぶ→遊んで
  - む→んで：読む→読んで
  - る→って：作る→作って
- 一段（グループ2）：る→て：食べる→食べて
- 不規則（グループ3）：する→して、来る→来て（きて）

**动漫例**：「待って！それやばいって！」（等等！那个不妙啊！）

### 5. た形（过去形）

て形把て→た、で→だ即可：食べて→食べた、読んで→読んだ

**动漫例**：「昨日、映画を見た。」（昨天看了电影。）

### 6. ない形（否定形）

**变形规则**：
- 五段：う段→あ段+ない：買う→買わない、書く→書かない（※ある→ない）
- 一段：る→ない：食べる→食べない
- 不規則：する→しない、来る→来ない（こない）

**动漫例**：「そんなの、絶対に許さない！」（那种事，绝对不原谅！）

### 7. い形容詞・な形容詞

```
い形容詞：直接修饰名詞（高いビル）→ 否定：くない（高くない）
な形容詞：+な修饰名詞（静かな部屋）→ 否定：じゃない（静かじゃない）
```

**动漫例**：「この世界は広いなあ。」（这个世界真广阔啊。）
