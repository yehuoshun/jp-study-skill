### 方言/地域特有

**关西方言（関西弁）最多出现**：
- 〜へん（否定）：食べへん（食べない）、行かへん（行かない）
- 〜とる（〜ている）：しとる（している）
- 〜や/〜やで（だ/だよ）：そうやで（そうだよ）
- 〜ねん（〜のだ）：そうなんやで（そうなんだよ）
- あかん（ダメ）
- ほんま（本当）
- めっちゃ（とても）
- おもろい（面白い）
- なんでやねん！（为什么啊！）

**动漫典型角色**：
- 服部平次（名探偵コナン）— 関西弁
- 志村新八（銀魂）— 関西弁
- タツマキ（ワンパンマン）— 関西弁

## 角色语（キャラ語尾）

角色语是日语中用来塑造角色性格的语言模式，在动漫中非常常见。

### 男性语

| 语尾 | 语气 | 角色类型 | 例 |
|------|------|----------|-----|
| 〜だぜ | 强调/自信 | 熱血系男子 | 俺がやるぜ！ |
| 〜だぞ | 警告/提醒 | 保护者/兄贵 | 危ないぞ！ |
| 〜さ | 解释/主张 | 普通青年 | そうさ、それでいいんだ |
| 〜かい | 疑问（男） | 庶民/年上 | どこ行くんだい？ |
| 〜だな | 确认/感叹 | 普通男性 | いい天気だな |
| 〜ぜ | 招呼/引起注意 | 热情 | 聞いてくれよ、ぜ！ |
| 〜かよ | 反问/惊讶 | 青年 | 何だよそれ！ |
| 〜じゃねえか | 强调 | 粗鲁 | すげえじゃねえか！ |
| 〜な | 轻微命令 | 男性 | 早くしろよな |
| 〜てえ（〜たい） | 愿望 | 男/青年 | 勝ちてえ！ |

## 和制汉语特别提醒（陷阱词）

| 单語 | 日语含义 | 中文同字含义 |
|------|----------|-------------|
| 大丈夫（だいじょうぶ） | 没问题/没关系 | 男子汉大丈夫 |
| 勉強（べんきょう） | 学习 | 勉强 |
| 可愛い（かわいい） | 可爱 | 可（值得）爱？ |
| 手紙（てがみ） | 信 | 手纸 |
| 怪我（けが） | 受伤 | 怪我（my fault） |
| 丈夫（じょうぶ） | 结实/耐用 | 丈夫 |
| 真面目（まじめ） | 认真/严肃 | 真面目 |
| 結構（けっこう） | 相当好/不用了 | 结构 |
| 面白い（おもしろい） | 有趣 | 面白 |
| 迷惑（めいわく） | 麻烦/困扰 | 迷惑 |
| 新聞（しんぶん） | 报纸 | 新闻 |
| 機嫌（きげん） | 心情/情绪 | 机嫌（机器？） |
