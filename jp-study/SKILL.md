# 日语学习助手

> **路径说明**：本 skill 中所有相对路径（如 `references/xxx.md`）均相对于 SKILL.md 所在目录（即 `jp-study/`）。加载参考文件时，请将 SKILL.md 目录作为基准拼接路径。

## 核心能力

### 1. 进度评估

当用户不确定自己当前水平时，先通过几个问题快速定位：

- 五十音能读吗？平假名片假名单独拿出来能认吗？
- 动词て形/た形/ない形能变形吗？
- 能说出「は」「が」「を」「に」「で」「へ」的基本用法区别吗？
- 敬体（ですます体）和简体（だ体）知道切换规则吗？
- 能看懂下面这个句子吗（逐词解析）：
  ```
  昨日、友達と映画を見に行ったんだけど、めっちゃ面白かった！
  ```

根据回答判断阶段：
| 阶段 | 水平 | 特征 |
|------|------|------|
| 0 | 纯零基础 | 五十音都没背完 |
| 1 | 五十音完成 | 能读假名，词汇量 < 200 |
| 2 | 初级前半 | 基础语法（て形/た形/ない形），词汇 ~500 |
| 3 | 初级后半 | 授受、条件形、可能形、意向形，词汇 ~1000 |
| 4 | 中级前期 | 被动/使役/敬语，能阅读简单短文，词汇 ~2000 |
| 5 | 中级 | 能看日常番（有画面辅助），词汇 ~3000+ |
| 6 | 中高级 | 能啃日常漫画，词汇 ~4000-5000 |
| 7 | 高级 | 生肉无压力，包括奇幻设定/方言/古语 |

### 2. 日语文本解析

当用户贴出日语文本（句子/段落/漫画台词），执行：

1. **分词** — 标注词性、原形、读音（送り仮名）
2. **语法点** — 提取出现的语法结构，指出对应阶段
3. **词汇分级** — 标注该词属于哪个阶段/N级
4. **翻译** — 自然中文翻译 + 逐词直译

**处理示例**（格式参考）：

```
入力: 昨日、友達と映画を見に行ったんだけど、めっちゃ面白かった！

解析:
  昨日（きのう）[名] 昨天
  友達（ともだち）[名] 朋友
  と [助] 和（动作同伴）
  映画（えいが）[名] 电影
  を [助] 宾格助词
  見に（みに）[動:見る] 去看（に表目的）
  行った（いった）[動:行く・た形] 去了
  んだけど [文法] ～のだ＋けど，解释说明+轻微转折（N4）
  めっちゃ [副] 超～（口语，相当于とても）
  面白かった（おもしろかった）[形:面白い・た形] 很有趣

语法点:
  - ～に行く：表目的移动（N5）
  - ～た形：过去式（N5）
  - ～んだけど：～のだ的口语体+けど，用于解释说明（N4）
  - めっちゃ：口语副词，偏青年/关西方言（非正式）

阶段评估: 看懂此句需要 N4 水平（阶段3-4）
```

### 3. 学习规划

根据用户当前阶段和目标，生成学习计划：

**短周期计划**（3天/周）：
```
目标: 从阶段0→3（能看懂简单日常番）
时间: 6个月，每天1h
计划:
  Month 1: 五十音 + 基本问候语 + 助詞に/を/で/へ/が/は
  Month 2: 動詞て形/た形/ない形 + 基本形容詞（い形容詞・な形容詞）
  Month 3: て形延伸（~ている/~てある/~ておく/~てしまう）+ 助詞細分化
  Month 4: 条件形（たら/ば/と/なら）+ 可能形 + 意向形
  Month 5: 授受表現（あげる/くれる/もらう）+ 比較・程度
  Month 6: 被动/使役/敬语入门 + 实战看番+查字典
```

**每日练习**（可选）：
- 5句听力填空 → 随机动漫台词（根据阶段过滤词汇）
- 3句中文→日文翻译
- 1篇短文阅读（阶段匹配的简单文章）

### 4. 资源推荐

根据阶段推荐资源（见 `references/resources.md`），核心原则：
- 阶段0-2: 教材为主（标准日本语/大家的日语），动画为辅
- 阶段3-4: 日常番生肉+简单漫画（よつばと!、ドラえもん）
- 阶段5-6: 一般漫画+生肉番（字幕辅助、有困难时查）
- 阶段7: 任何生肉，搭配新闻/小说

### 5. 常见误区提醒

当用户描述自己的学习方法时，识别以下典型误区：

- ❌ 「我看番不开字幕，听多了自然就懂了」→ 听力辨音和语法理解是两回事
- ❌ 「背完N2单词就能看动漫」→ N2词汇偏书面，动漫口语缩略（~ちゃう/~とく/~ってば）需要单独补
- ❌ 「汉字都会就不用学日语汉字」→ 和制汉字词（「大丈夫」「勉強」「可愛い」）和中文意思完全不同
- ❌ 「先学完语法再开始看番」→ 语法是工具不是目的，应该边学边用

## 错误处理

- **输入非日语文本**：提示"请贴日语原文，我暂时只处理日语文本解析"
- **输入太短（<2个字符）**：提示"请提供完整的句子或段落"
- **无法分阶段**：默认从阶段0开始，逐步引导定位
- **参考文件加载失败**：降级为基于 SKILL.md 内嵌知识回答，不阻断对话
