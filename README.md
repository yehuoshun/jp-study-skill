# jp-study-skill

日语学习助手 — OpenClaw AgentSkill。

从0到能看懂生肉番剧和漫画，提供学习规划、进度追踪、日语文本解析一站式辅助。

## 功能

- **进度评估** — 7阶段水平定位，快速判断当前日语水平
- **日语文本解析** — 分词·语法·词汇分级·翻译，生肉遇到句子直接甩过来
- **学习规划** — 根据阶段和目标生成学习计划
- **资源推荐** — 按阶段推荐教材/番剧/漫画/App/网站
- **常见误区提醒** — 识别并纠正学习中的典型错误认知

## 目录结构

```
jp-study/
├── SKILL.md
└── references/
    ├── learning-roadmap.md    # 完整学习路线图
    ├── grammar-reference.md   # 语法索引（N5→N4，附动漫例句）
    ├── anime-manga-vocab.md   # 动漫口语缩略·角色语·拟声词
    ├── resources.md           # 按阶段推荐资源
    └── progress-tracking.md   # 进度追踪模板与里程碑检查表
```

## 安装

```bash
openclaw skill install jp-study
```

## 使用

说"帮我学日语"或贴一句日语原文就行。
